# Shamiz & Safana – Wedding Invitation Website

An elegant, full-screen scrolling wedding invitation website for Shamiz A & Safana Hashim, with a rich maroon and ivory theme inspired by traditional South Asian wedding aesthetics.

## Features

- **6 full-screen slides** with smooth scroll-snap navigation
- Live countdown timer to the wedding date (July 23, 2026)
- CSS-drawn floral corner ornaments on every slide
- Couple silhouette illustration on the welcome slide
- Floating animated rose petal accents
- Navigation dot indicators
- Google Maps directions link
- Fully responsive for mobile and desktop

## Key Technologies

- [TanStack Start](https://tanstack.com/start) – React full-stack framework
- [Tailwind CSS v4](https://tailwindcss.com/) – utility-first styling
- [Vite](https://vite.dev/) – build tool
- [Netlify](https://netlify.com/) – deployment platform

### Fonts (Google Fonts)
- **Great Vibes** – romantic script for names
- **Cinzel** – classical display for headings
- **Cormorant Garamond** – refined serif for body text
- **Lato** – clean sans-serif for labels

## Running Locally

```bash
npm install
npm run dev
```

The site runs on [http://localhost:3000](http://localhost:3000).

To use Netlify features locally (edge functions, etc.):

```bash
netlify dev --port 8889
```
